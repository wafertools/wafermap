§18 — Advanced: the rendering pipeline createWafer · generateDies · clipDiesToWafer · applyOrientation · applyProbeSequence · transformDies · generateReticleGrid · buildView · toCanvas
The manual pipeline gives you full control over every step: createWafer → generateDies → clipDiesToWafer → applyOrientation → applyProbeSequence → enrich with test data → generateReticleGrid → buildView → toCanvas. Use this when you need to intercept or customise individual stages — for example to inject custom enrichment, apply a non-standard probe path, or integrate with a server-side pipeline. For most use cases buildWaferMap + renderWaferMap is simpler. Controls above drive toCanvas directly — no built-in toolbar.
