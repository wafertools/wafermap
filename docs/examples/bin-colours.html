§5 — Bin colours across a full program 15 hard bins · 32 soft bins · 2 pass grades · 4 wafers
A logic chip at wafer sort, with the kind of bin list a real program has: hard bins 1 and 2 are both passes (two speed grades), the failing hard bins run from 3 to 20 with gaps, and every hard bin has soft bins numbered under it (1502 is soft bin 2 of hard bin 15). Each failure mode has its own pattern — opens around the edge, a cluster of shorts, IDDQ at the centre, a memory BIST scratch — so you can match a colour to a shape. A bin's colour comes from its number: passing bins take greens counting from bin 1, and failing bins take the fail colours counting from bin 2 — so bin 3 is always the second fail colour, and red (bin 2's) goes unused here because bin 2 passes. Colour never depends on how many dies a bin has, so hard bin 7 is the same colour on every wafer here and in any other lot of this program. Use the toolbar's mode picker to switch to Soft Bin — the 29 failing soft bins outnumber the palette's 19 fail colours, so some share a colour and the Data warnings indicator names them. The Palette menu switches to Colour-blind safe, which has fewer colours and so more sharing.
