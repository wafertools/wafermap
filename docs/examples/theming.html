wafermap
Theming — --wmap-* custom properties set the tokens on an ancestor of the render container; chrome + canvas follow
wmap's chrome (toolbar, gallery cards, summary panel) and the wafer canvas (background, axis, grid) are themed entirely through --wmap-* CSS custom properties, each with a light default. Set them on any ancestor of the render container and everything wmap draws follows — switch themes below to watch the gallery re-theme live. The data palette (bin colours of the dies) is separate (colorScheme) and deliberately does not follow the chrome accent. See the token reference in the API docs.
