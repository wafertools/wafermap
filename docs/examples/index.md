# Examples

Live interactive demos. Each opens a standalone page rendered in the browser.

## Start here

- [Your first wafer map](first-map.html) — minimal two-call example, no CSV
- [Loading CSV data](csv-data.html) — parse and map real columnar data
- [Geometry inference](geometry.html) — omit die size and let the library infer it
- [Partial data](partial-data.html) — anchoring the wafer centre for partial coverage, and why sparse data doesn't need it
- [Bins and yield](named-bins.html) — named hard bins, pass/fail colours, yield label
- [Test values](test-values.html) — parametric measurements, spec limits, colorbar
- [Retests](retests.html) — multi-touch probe sequences and retest policy

- [Display control](display-control.html) — rotation, flip, plot mode, colour scheme

- [Lot gallery](gallery.html) — card grid of multiple wafers with shared controls
- [Web Worker](worker.html) — off-main-thread build for large datasets
- [Custom colour schemes](color-schemes.html) — register your own bin/value palette
