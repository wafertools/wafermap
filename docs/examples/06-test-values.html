§6 — Working with test values Continuous parametric data · testDefs for labels and units
Continuous parametric data stored in die.testValues as a testNumber → value map. testDefs gives each test a name and unit — the toolbar mode menu, tooltips, and colorbar all update automatically. Vth has spec limits defined (limitLow / limitHigh): out-of-spec dies appear in blue/red in Test Value mode. Enable Spec pass/fail (via the Overlays menu or the button below) to replace the gradient with categorical pass·fail-low·fail-high colouring. The button is disabled for tests without limits. Use the toolbar bracket button to switch the colorbar between the spec window and the full data range.
