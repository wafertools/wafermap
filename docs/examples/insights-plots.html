Plots, tables and attributes insights.plots · onPlotsChange · defaultView · attributes · readPlotsFile / writePlotsFile
The Insights Plot tab is a chart builder, and the library keeps nothing: you hand it the list of saved plots in insights.plots and keep it current from insights.onPlotsChange (here, in localStorage). A plot is a recipe with no lot in it, so the same list draws on the next lot; one whose test the open lot lacks stays in the list, greyed with the reason. Two plots are supplied below to start from: Vth by process split (a box on a wafer attribute) and yield by reticle cell (a bar split by a die field, offered because the lot has a reticleConfig). Add, edit or delete some, reload the page, and they are still there. Export plots… writes the same list as a wafermap-plots file (writePlotsFile); Import plots… reads one (readPlotsFile). The Data tab shows the lot as tables (statistics, dies, wafers) with CSV export, and right-clicking a map, a card or a chart mark opens the drilldown on exactly the dies it counts. attributes names the wafer attributes: processSplit is called Process split and offered as a Group by, progRev is shown on the header strip and in the Wafers table but kept out of the Group by list (facet: false), and testDate is a date, grouped by day.
